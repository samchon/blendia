# Blendia unit tests

These cases verify Blendia's first-party command-line grammar, bridge envelopes and framing, object and scene validation, material and camera/light readback, publication metadata, captured output, and script-job state. They run without a Blender installation.

See [UNIT_TESTS.md](UNIT_TESTS.md) for execution and coverage. Actual engine integration belongs to the separate [Blender tests](../test-blender/TESTING.md).

Implementation and verification are tracked in [issue #6](https://github.com/samchon/blendia/issues/6).
